# 模块化后的项目结构

入口负责启动和组装，业务模块处理各自的规则。数据库、输出目录和微信身份绑定的位置沿用现有设置。

```text
wechat-assistant-v01/
├─ app.py                       原启动入口、兼容导入
├─ zhishi/
│  ├─ __main__.py                python -m zhishi 入口
│  ├─ config.py                  项目路径、模型别名、Excel 运行环境
│  ├─ runtime.py                 组装服务、HTTP 服务与后台线程生命周期
│  ├─ service.py                 对话和业务协调

│  │  └─ clock.py                北京时间与日期解析
│  ├─ tasks/
│  │  ├─ service.py              待办创建、完成、取消、延期
│  │  └─ reminders.py            提醒队列和通道提交
│  ├─ models/
│  │  ├─ intents.py              规则优先的意图识别
│  │  ├─ client.py               可替换的模型接口
│  │  └─ settings.py             模型配置校验

│  │  ├─ documents.py            项目文档、输入和收件人校验
│  │  ├─ excel.py                执行 Excel 技能，生成验收材料
│  │  ├─ artifacts.py            文件访问、摘要校验、验收版本绑定

│  └─ static/
│     ├─ styles.css              页面样式
│     ├─ api.js                  带本机凭证的请求封装
│     ├─ ui.js                   DOM、时间和提示工具
│     ├─ app.js                  待办、设置和微信连接交互
│     ├─ workflow.js             今日工作与验收交互
```

## 启动和验证

仍可运行 `python app.py` 或 `start.ps1`，也可以运行 `python -m zhishi`。两种 Python 启动方式都支持原来的 `--port` 和 `--database` 参数。

执行全部 Python 测试：

```powershell
python -m unittest discover -v
```

执行 OpenClaw 插件测试：

```powershell
& '.runtime/node-v24.22.1-win-x64/node.exe' --test integrations/zhishi-wechat/index.test.mjs
```

`runtime.build_pilot(..., enable_wechat=False)` 可启动不创建微信凭据的本地服务对象；测试和调用方也可通过 `transport` 注入通知通道。只有正式启动过程会创建后台线程，导入模块不会启动服务。

## 后续修改位置

- 修改模型提供方接口：`models/client.py`；修改允许的模型别名：`config.py` 或原环境变量。
- 修改任务文档规则：`workflows/documents.py`；修改表格计算：`workflows/excel_worker.mjs`。
- 修改验收或版本规则：`workflows/service.py`；修改文件校验：`workflows/artifacts.py`。
- 添加发送渠道：在 `channels/` 下实现适配，再由 `runtime.py` 组装；需要新增入站接口或页面时，在 HTTP 和网页模块登记。
- 修改网页：在 `web/` 中修改结构、样式或对应交互模块。浏览器模块通过显式 import 共享工具，不依赖全局变量互相调用。

根目录的 `workflow.py` 和 `wechat_bridge.py` 保留常用类的兼容导入，`wechat_connect.py` 保留原扫码命令入口。新的代码应直接导入 `zhishi` 包。

本次是代码组织调整。当前运行范围仍为本机单用户，企业身份、多员工权限、生产托管等能力仍需单独实施。

## 源码打包

运行 `python scripts/package.py` 更新项目压缩包。仅打包源码、文档、固定测试样例和示例输入，排除数据、运行时、目录联接和实际收件箱。

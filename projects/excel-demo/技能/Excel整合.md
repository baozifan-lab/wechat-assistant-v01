# excel.merge.v1

版本：1.0。用途：将本示例中的 XLSX 明细追加为一个工作表。

1. 首行是表头，读取第一个工作表，原文件保持不变。
2. 固定输出字段：业务编号、日期、部门、客户、金额、来源文件、来源行。
3. 表头别名：单号→业务编号，业务日期→日期，团队→部门，客户名称→客户，销售额→金额。
4. 日期统一为 yyyy-mm-dd，金额保留数值类型和两位小数。零金额是有效数据。
5. 相同业务编号且全部业务字段一致时去重。内容冲突阻止交付。
6. 缺少必填值、日期或金额无效的行隔离，写入异常清单，不以零或空值掩盖。
7. 核对：输入行数 = 保留行数 + 完全重复行数 + 隔离行数；输出金额合计与独立计算一致。
8. 生成一个结果工作表、预览、检查摘要和异常清单，交本人验收。

执行器：`workflows/excel_worker.mjs`。注册表固定绑定此执行器，文档不能指定任意终端命令。

首版只处理 .xlsx、首行表头、Excel 1900 日期系统、普通明细值；含源公式、加密、宏、复杂多表关系等情况应补充规则后扩展技能。每份最多 10000 行，每次最多 20 份文件。

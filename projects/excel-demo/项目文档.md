# 今日报表整合示例

本项目全部使用编造的示例数据和模拟收件人，用于验证工作流程。

## 今日需要完成的工作

把“待处理”中的两份 Excel 整合成一个工作表。调用 `excel.merge.v1` 技能，统一表头、日期和金额，保留来源文件与来源行。

完全一致的业务编号记录只保留一次。必填项缺失或日期／金额无效的行移到异常清单。相同业务编号但内容冲突时停止交付，不能自行选择一条。

完成后发送工作簿、预览和检查摘要给本人微信。本人明确确认指定任务和版本后，再投递给下面列出的模拟收件人。模拟投递仅复制到本地收件箱，不联系真实人员。

## 可执行任务定义

以下配置由后台读取。路径相对于本项目目录；操作技能必须来自已注册列表。

```workflow
{
  "task_id": "daily-excel-demo",
  "title": "今日报表整合（示例）",
  "demo": true,
  "work_date": "today",
  "skill": "excel.merge.v1",
  "input_directory": "待处理",
  "input_pattern": "*.xlsx",
  "recipients": ["demo-finance", "demo-project"],
  "auto_run": false,
  "run_at": "09:00",
  "timezone": "Asia/Shanghai",
  "acceptance": {
    "required_fields": ["业务编号", "日期", "部门", "客户", "金额"],
    "duplicate_policy": "identical_only",
    "invalid_policy": "quarantine",
    "conflict_policy": "block"
  }
}
```

示例默认手动开始。在微信发送“开始今日工作”即可执行。要验证定时读取，可把 `auto_run` 改为 true 并填写北京时间 `run_at`；同一天同一份任务不会因定时扫描而重复执行。

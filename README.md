# 知事 · 微信工作助理

Python 本地工作助理，提供待办提醒、微信连接、任务协作、固定工作流及多人协作后端。网页使用 HTML、CSS 和 JavaScript。

## 源码目录

| 目录 | 内容 |
|---|---|
| `zhishi/` | 服务、任务、模型接口、微信通道、工作流与团队后端 |
| `web/` | 页面、样式和浏览器脚本 |
| `integrations/` | 微信桥接插件源码及包定义 |
| `workflows/` | 文件处理技能代码 |
| `migrations/` | 数据库结构迁移 SQL |
| `scripts/` | 启动辅助、检查、演示、备份与迁移工具源码 |
| `tests/` | 自动化测试源码 |

## 本地启动

需要 Python 3.11 或更新版本。在项目目录执行：

```sh
python app.py
```

默认页面地址为 `http://127.0.0.1:8765/`。多人后端使用 `python -m zhishi --mode team` 显式启动。

微信、模型服务、Excel 技能及数据库相关功能需要自行准备对应运行库、账号与本地配置。示例环境变量见 `.env.example`；程序不会自动加载 `.env`。`wechat.ps1` 依赖另行安装的本地 Node/OpenClaw 运行环境。

## 数据和记录

本仓库当前版本仅发布源码、数据库结构脚本和示例配置。本地数据库、聊天、任务状态、成果文件、微信授权、模型密钥、运行日志、开发验证记录和证据包均未包含。样例项目及测试数据也未附带，依赖这些材料的演练和测试需自行准备对应输入；此源码副本不作为开箱即用的完整安装包。

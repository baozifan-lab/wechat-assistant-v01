# 知事 · 企业级主动式智能体

知事是一款**以微信为交互入口的企业级主动式智能体**。它按照任务安排，主动联系负责人和执行人员，跟进回复，调用已配置的技能，核对成果并汇报结果。

员工通过微信接收和处理任务；管理员通过桌面工作台配置人员、安排工作、查看进度和处理异常。

## 使用指南

完整步骤见[知事使用指南](docs/使用指南.md)，包括启动服务、连接员工微信、配置模型接口、创建任务、协作回复、成果核对、文件更正和常见问题。

## 主要功能

| 功能 | 作用 |
|---|---|
| 主动发起任务 | 按配置的时间派发任务，联系负责人和执行人员 |
| 员工分工与跟进 | 安排一人或多人执行，跟踪接单、完成和受阻状态 |
| 微信交互 | 员工通过绑定微信接收通知和回复当前任务 |
| 技能与流程执行 | 在已配置的协作模板中调用固定技能，推进阶段和交接 |
| 成果核对与汇报 | 按对应流程检查输入和成果，核对通过后汇报结果 |
| 桌面管理工作台 | 查看任务、管理连接、配置接口和处理文件更正 |

实际可用的流程取决于运行环境、任务模板和技能配置。当前桌面工作台用于本机管理；多人后端需要单独初始化和部署。

## 本地启动

需要 Python 3.11 或更新版本。在项目目录执行：

```sh
python app.py
```

默认页面地址为 `http://127.0.0.1:8765/`。多人后端使用 `python -m zhishi --mode team` 显式启动。

微信、模型服务、Excel 技能及数据库相关功能需要自行准备对应运行库、账号与本地配置。示例环境变量见 `.env.example`；程序不会自动加载 `.env`。`wechat.ps1` 依赖另行安装的本地 Node/OpenClaw 运行环境。

## 数据和记录

本仓库当前版本仅发布源码、数据库结构脚本、示例配置和说明文档。本地数据库、聊天、任务状态、成果文件、微信授权、模型密钥、运行日志、开发验证记录和证据包均未包含。样例项目及测试数据也未附带，依赖这些材料的演练和测试需自行准备对应输入；此源码副本不作为开箱即用的完整安装包。
